# AI Summarizer

Простое веб-приложение: вставил текст или распознал голос — получил краткое резюме.

Провайдеры: **Groq** (бесплатный тариф, без карты), OpenAI, Anthropic.

## Как запустить

1. Открой сайт или `index.html` в браузере.
2. Выбери провайдер. Для тестов без денег — Groq.
3. Вставь API ключ:
   - Groq: `gsk_...` с [console.groq.com/keys](https://console.groq.com/keys)
   - OpenAI: `sk-...`
   - Anthropic: `sk-ant-...`
4. Вставь текст **или** распознай голос и нажми «Сократить».

Ключ хранится только в браузере.

## Голос (Whisper)

1. Groq использует `whisper-large-v3`, OpenAI — `whisper-1`.
2. Нажми «Запись» и говори, затем «Стоп», **или** выбери аудиофайл.
3. Нажми «Распознать» — транскрипт появится в поле текста.
4. Дальше можно сократить текст выбранным провайдером.

## Стек

- Чистый HTML/CSS/JS, без сборки.
- Вызывает API нейросетей прямо из браузера.
- Groq: `openai/gpt-oss-20b` + Whisper Large v3.
