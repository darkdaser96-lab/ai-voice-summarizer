# AI Summarizer

Простое веб-приложение: вставил текст или распознал голос через Whisper — получил краткое резюме через OpenAI или Anthropic.

## Как запустить

1. Открой `index.html` в браузере.
2. Вставь API ключ (OpenAI `sk-...` или Anthropic `sk-ant-...`).
3. Вставь текст **или** распознай голос и нажми «Сократить».

Ключ хранится только в браузере, никуда не отправляется на наш сервер.

## Голос (Whisper)

1. Нужен OpenAI-ключ (`sk-...`) — Whisper работает только через OpenAI API.
2. Нажми «Запись» и говори, затем «Стоп», **или** выбери аудиофайл.
3. Нажми «Распознать» — транскрипт появится в поле текста.
4. Дальше можно сократить текст выбранным провайдером.

## Стек

- Чистый HTML/CSS/JS, без сборки.
- Вызывает API нейросетей прямо из браузера.
- Распознавание: OpenAI Whisper (`whisper-1`).
